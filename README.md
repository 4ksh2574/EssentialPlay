# EssentialPlay — Cinema, everywhere

A responsive, cinematic global movie-discovery hub.

## MVP
- Search movies and TV titles using TMDB.
- Browse trending titles and cinema by country.
- View synopsis, ratings, runtime, language and trailers.
- Find licensed streaming availability through provider links.
- Save a watchlist locally on the current device.

## Deploy on GitHub Pages
Open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, then Save. The site URL will be https://4ksh2574.github.io/EssentialPlay/.

## Connect TMDB
In EssentialPlay, open Settings and paste a TMDB API Read Access Token. Generate one at https://www.themoviedb.org/settings/api. The token is stored in this browser's local storage and sent directly to TMDB.

Movie metadata and images are provided by TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.

## Playback and licensing
EssentialPlay is a discovery and aggregation interface, not an unauthorized streaming host. It links to official licensed providers. Direct playback requires rights-holder permission and authorized provider integrations; no app can legally stream every copyrighted movie without licenses.
